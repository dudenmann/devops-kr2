# Происхождение

Оригинал kr2-template не предоставлен. Приложение и requirements восстановлены по таблицам 5–6 задания с согласия владельца стенда; проверить тождество оригиналу невозможно. main содержит явно обозначенную небезопасную учебную заготовку, созданную для тренировки ревизии, а не полученную от преподавателя. Пароль в main — заведомо нерабочая заглушка. Действующий пароль генерируется только на сервере.

Таблица ревизии описывает только эту восстановленную заготовку. Для буквального выполнения ревизии преподавательского шаблона и требования не изменять его app.py/requirements.txt необходим оригинал. После фиксации восстановленной базы логика app.py и requirements.txt не меняется; добавляется только требуемый комментарий.
