# Ревизия восстановленной учебной заготовки

Оригинальный kr2-template отсутствует. Эта таблица относится к нашей явно обозначенной учебной заготовке коммита 43ca291, а не к неизвестному шаблону преподавателя. Её нельзя выдавать за результат ревизии оригинала.

| № | Файл, строка исходной базы | Дефект | Последствие | Исправление |
|---|---|---|---|---|
| 1 | Dockerfile:4 | COPY . . до pip | Изменение app.py инвалидирует слой установки зависимостей | Сначала COPY requirements.txt и pip, затем app.py |
| 2 | Dockerfile:4; отсутствующая .dockerignore | Не исключён .env из контекста | Секрет может попасть в слой при COPY . . | .dockerignore и копирование только нужных файлов |
| 3 | Dockerfile:6–7; отсутствует USER | Процесс работает как root | Ошибка/уязвимость приложения получает расширенные права внутри контейнера | Пользователь app, USER app |
| 4 | Dockerfile:7 | CMD в shell-форме | PID 1 — оболочка, сигналы могут не достигать Gunicorn; задержка docker stop | JSON exec CMD |
| 5 | Dockerfile:7 | Привязка к 127.0.0.1 внутри контейнера | Docker направляет трафик на адрес сетевого интерфейса, где приложение не слушает | Bind 0.0.0.0:8004 |
| 6 | Dockerfile:6–7 | Порт 5000 вместо варианта 8004 | Публикация варианта направляется на неслушающий порт | EXPOSE и Gunicorn 8004 |
| 7 | .env:1; отсутствующая .gitignore | Файл окружения отслеживается | Действующий пароль при таком подходе остаётся в истории после удаления | Удалить из индекса, добавить ignore, новый случайный серверный пароль |

В учебной базе находится только нерабочая заглушка. Действующий пароль генерируется на сервере, в Git и образ не передаётся. app.py восстановлен по публично заданному интерфейсу; после фиксации базы добавлен только комментарий # KR2: Dudnik. requirements.txt неизменён относительно базы. Проверка тождества оригиналу без его получения невозможна.
